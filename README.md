# BeefPlusTaskManager

BEEF+（神戸大学の学習支援システム）の課題管理と自動ログインを行う Chrome 拡張機能です。

> 本拡張は個人開発の非公式ツールです。神戸大学および BEEF+ 運営とは無関係であり、利用による損害について開発者は責任を負いません。自己責任でご利用ください。

## 主な機能

### 📋 課題通知
- BEEF+ の課題一覧を解析し、ローカルに保存
- 締切の 24/12/3/1 時間前にデスクトップ通知（1 分以内なら即時通知）
- ポップアップで課題一覧と残り時間を確認、クリックで課題ページを新しいタブで開く
- 残り時間を詳細表示（2日以内は「あと1日と12時間」形式）
- 緊急度に応じた色分けインジケーター

### 🔐 自動ログイン
- 学籍番号とパスワードを保存し、BEEF+ ログインページで自動入力
- 保存した情報はブラウザのローカルストレージにのみ保存
- いつでも削除可能

## 動作の仕組み

### 課題取得
1. BEEF+ の「課題・テスト一覧」ページ（`https://beefplus.center.kobe-u.ac.jp/lms/task*`）を開くと、content script が課題情報を取得します。
2. 取得した課題はブラウザのローカルストレージに保存され、バックグラウンドで通知スケジュールが再設定されます。
3. 以降、指定のタイミングで通知が表示されます。再取得が必要なときは再度課題一覧ページを開いてください。

### 自動ログイン
1. ポップアップの「自動ログイン」タブで学籍番号とパスワードを保存します。
2. BEEF+ のログインページにアクセスすると、保存した情報が自動で入力されます。

## 必要なもの
- Google Chrome（Edge など Chromium 系でも動作する可能性あり）
- BEEF+ にログイン済みで課題一覧ページを開ける環境
- 通知権限（初回起動時に求められたら許可してください）

## インストール

1. GitHub のリポジトリページで `Code` → `Download ZIP` から最新コードをダウンロード
2. ZIP を任意のフォルダに展開
3. Chrome で `chrome://extensions/` を開き、右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、展開したフォルダを選択
5. 拡張が追加されたら、通知権限が有効になっているか確認

## 使い方

### 課題一覧
1. BEEF+ にログインし、「課題・テスト一覧」ページを開く（これで課題を取得）
2. 拡張アイコンをクリックしてポップアップを開くと、取得済みの課題と残り時間が表示されます
3. 課題をクリックすると該当ページを新しいタブで開きます
4. 締切が近づくと通知が届きます（24/12/3/1 時間前、1 分以内なら即通知）

### 自動ログイン
1. 拡張アイコンをクリックし、「自動ログイン」タブを選択
2. 学籍番号とパスワードを入力して「保存」をクリック
3. 以降、ログインページにアクセスすると自動入力されます
4. 保存情報を削除するには「削除」ボタンをクリック

## 注意点・制限
- 課題の再取得は「課題・テスト一覧」ページを開いたタイミングで行われます
- BEEF+ のページ構造や日付表示形式が大きく変わると取得に失敗する場合があります
- 通知時刻はブラウザが起動している間にのみ発火します
- 取得したデータおよびログイン情報はローカルストレージにのみ保存され、外部に送信しません
- 自動ログインは最大3回まで試行し、ループを防止します

## トラブルシューティング
- **通知が出ない**: Chrome の通知権限を確認し、ブラウザが常駐しているかを確認
- **課題が表示されない**: 課題一覧ページでログイン状態を確認
- **自動ログインが動作しない**: 「自動ログイン」タブで情報が保存されているか確認
- **反映されない変更がある**: 課題一覧ページをもう一度開いて再取得

## 開発者向けメモ

### ファイル構成
| ファイル | 説明 |
|---------|------|
| `manifest.json` | Manifest V3 設定 |
| `content.js` | 課題一覧ページから課題情報を抽出 |
| `content-autologin.js` | ログインページで自動入力 |
| `background.js` | 通知アラームのスケジューリング |
| `popup.html/js/css` | ポップアップ UI |

### デバッグ
- `chrome://extensions/` の「サービスワーカーを検査」「コンテンツスクリプトを検査」を利用
